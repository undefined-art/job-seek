# Support

This project is provided as-is under the MIT License and is maintained in
spare time. Community support is limited.

## Getting Help

- **Documentation**: Check the `README.md` first — it covers setup,
  configuration, and common troubleshooting steps.
- **Issues**: For confirmed bugs or feature requests, open an issue using the
  provided bug report template at
  <https://github.com/undefined-art/job-seek/issues/new/choose>.

## What to Expect

- Bug reports and feature requests are reviewed on a best-effort basis.
- There is no guaranteed response time or SLA.
- Pull requests that include tests are reviewed more quickly.

## Not Covered

- General Git/Docker/Go/Next.js tutorials
- Custom model configuration outside the documented `MODEL_NAME` variable
- Deployment assistance for specific hosting providers
